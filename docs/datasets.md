# Datasets — provenance, structure, and caveats

## Source file (immutable)

`datasets/raw/Neves/BH_HTE_Curated_Dataset_v20260219.csv` — 27,497 Buchwald–Hartwig C–N coupling
reactions curated from 8 sources. Binary `labels` (1 = feasible, defined **`Yield ≥ 10 %`** —
verified below) and a continuous `Yield`. This file is **never modified**; all derived data is
regenerated by `scripts/01_split_raw_dataset.py` and carries a provenance record
(`datasets/processed/split_report.json`, including the raw SHA-256
`247473787c33fb22…`). *(Note: `datasets/raw/` was reorganised into one folder per source —
`Neves/`, `Cernak/`, `ORD/`, `Pistachio/`; the curated file now lives under `Neves/`.)*

### Columns (raw)
- `Source` — dataset of origin (see table below).
- `Aryl SMILES`, `Amine SMILES` — the two coupling substrates.
- `Catalyst Name` / `Catalyst SMILES`, `Base Name` / `Base SMILES`, `Solvent Name` / `Solvent SMILES`.
- `Product SMILES`.
- `Yield` (float), `labels` (0/1).
- `DRFP`, `DRFP_subst_prod`, `QM` — **see caveat below (unusable as stored).**
- `iteration_{0..9} cluster` / `iteration_{0..9} train_test` — a pre-existing 10-fold clustered
  CV scheme baked into the file (list-of-strings per row). Available if we want to reuse Neves-style
  splits, but our primary split is source-based (see below).
- `Additive_present` + `Additive_*` engineered flags — non-zero **only** for the Ahneman source.

## The JnJ HTE 2024 test space (for unlabeled-space generation)
110 aryl halides × 68 amines, but only **888 of 7,480** possible (aryl, amine) pairs were measured
(~12 %). 32 catalysts, 8 bases, 6 solvents. Four dominant "general-condition" sets share base
**P2Et** with ligands RuPhos / BrettPhos / XPhos / P(tBu)₃ (~2,374 rows). Conditions-per-pair range
4–672 (mean ~13). → The **unlabeled combinatorial space** we generate is (a defensible subset of)
the aryl × amine × general-conditions grid, **minus** the measured test reactions, with strict
canonical-SMILES/reaction-hash de-duplication against the test set to prevent leakage. The exact
"general conditions" definition and OOD split follow the Neves paper — see
`docs/literature/notes/bh-JnJ-testset-spec.md`.

## ⚠️ Caveats

1. **`DRFP` / `DRFP_subst_prod` / `QM` are truncated NumPy string reprs**, e.g.
   `"[0 1 1 ... 1 0 0]"` — the `...` means values are elided; they are **not** recoverable feature
   vectors. **Recompute** DRFP from reaction SMILES with the `drfp` package and QM/2D descriptors
   with RDKit / Auto-QChem. Do not parse these columns as features.
2. **Ahneman drop** — `Dreher Doyle 2018` is the isoxazole-additive screen and the only
   additive-bearing source, but the additive identity is absent from the file (23 additive
   experiments collapse to identical featurisations). Dropped. See
   `docs/decisions/001-drop-ahneman.md`.
3. **Label definition (CONFIRMED)** — `labels = (Yield ≥ 10 %)`. Verified programmatically: this
   threshold reproduces `labels` with **99.9 %** agreement across all 27,497 rows; in the JnJ subset,
   label-0 yields span 0–9.9 % and label-1 span exactly 10.0–114.3 %. The 10 % floor ≈ the
   direct-to-biology assay-readability floor (~12 %, Cernak) — predicting `labels` ≈ predicting
   D2B-assayability.
4. **Leakage** — literature sources may share substrates/conditions with JnJ. A leakage audit
   (canonicalisation + reaction hashing + substructure overlap) must run before any source is used
   as training positives. See `docs/literature/notes/data-sources-catalog.md`. Verified so far: the
   6 bundled literature sources share **0 amines and ≤2 aryls** (hence 0 aryl–amine pairs) with JnJ.
